# Dirección visual provisional de Case-Tech

## Concepto

La tienda combinará una base tecnológica oscura con un acento naranja energético. La composición será clara y comercial, con tarjetas de producto amplias, búsqueda visible y llamadas a la acción directas. El objetivo es que el comprador pueda identificar rápido la marca, el modelo compatible, el precio y la disponibilidad.

## Sistema editable

Estos valores se tratarán como tokens para poder modificarlos después desde el tema:

```css
:root {
  --ct-ink: #111827;
  --ct-ink-soft: #374151;
  --ct-orange: #f97316;
  --ct-orange-dark: #c2410c;
  --ct-sand: #fffaf5;
  --ct-surface: #ffffff;
  --ct-line: #e5e7eb;
  --ct-success: #15803d;
  --ct-radius-card: 18px;
  --ct-radius-button: 10px;
}
```

La tipografía se mantendrá como una elección editable del tema. Se priorizará una sans-serif de alta legibilidad para el cuerpo y una variante de mayor carácter para titulares, sin depender de una fuente fija para que el proyecto pueda cambiarla más adelante.

## Logo provisional

El concepto será un contorno de case de teléfono con la palabra “tech” integrada o superpuesta. La primera versión generada será conceptual; el texto final del logotipo podrá refinarse como SVG/CSS para asegurar legibilidad exacta.

## Imágenes de producto

Se usarán renders de prueba de cases y micas sin logotipos oficiales. Cada imagen tendrá un nombre relacionado con la marca y modelo demo, pero la imagen debe poder reemplazarse desde la biblioteca de medios de WordPress sin modificar las plantillas.

## Referencia

La referencia de Figma inspira la estructura de navegación, catálogo, detalle, confianza y recomendaciones. No se copiarán sus elementos gráficos, textos ni identidad.
